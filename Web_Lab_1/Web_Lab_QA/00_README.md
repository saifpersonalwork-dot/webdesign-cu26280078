## Kaise chalayein
- **Lab 1, 2, 3:** code ko `.html` file mein save karke browser mein kholo. Jahan sirf `<body>` ka hissa diya hai wahan ye boilerplate lagao:
  ```html
  <!DOCTYPE html>
  <html lang="en"><head><meta charset="UTF-8"><title>Lab</title></head>
  <body>
     ...yahan code...
  </body></html>
  ```
- **Lab 4, 7:** XAMPP (Windows) ya `sudo apt install apache2 php libapache2-mod-php php-mysql mariadb-server` (Ubuntu). Files `htdocs` ya `/var/www/html` mein rakho. URL: `http://localhost/...`
- **Lab 5, 6:** Python 3 + Apache CGI/mod_wsgi, `pip install pymysql mysql-connector-python sqlalchemy`.
- Passwords (`root`, `lab123` wagairah) sirf practice ke liye hain, real project mein mat rakho.
- Practical file mein apne browser/terminal ke screenshots lagana.
